#  Ativos Visuais e Marcas — `frontend/public/`

Este diretório contém os arquivos de imagem, logotipos e favicons compartilhados entre as aplicações de frontend do **labMU**.

---

##  Arquivos Disponíveis

| Arquivo | Formato | Aplicação |
| :--- | :---: | :--- |
| `Logo-unicap.png` | PNG | Logotipo oficial da Universidade Católica de Pernambuco com fundo transparente, utilizado nos cabeçalhos das telas de login, cadastro e na sidebar do sistema. |
| `MUSARQ_Logo.svg` | SVG | Logotipo vetorial do Museu de Arqueologia e Ciências Naturais da UNICAP. |
| `favicon.ico` | ICO | Ícone de favoritos exibido na aba do navegador para navegadores clássicos. |
| `favicon.png` | PNG | Favicon de alta resolução em formato PNG para navegadores modernos e atalhos móveis. |
